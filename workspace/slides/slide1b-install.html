Installation

Option 1: NPM / PNPM

pnpm add -g scud-task

# or: npm install -g scud-task

Option 2: Cargo

cargo install scud-cli

Initialize

cd your-project && scud init

Prerequisites

Node.js 18+ (npm) or Rust (cargo)

AI API key (xAI, Anthropic, OpenAI)

What you get

+

Fast Rust CLI binary

+

.scud/ directory for task storage

+

SCG format (compact text)

+

Claude Code slash commands
